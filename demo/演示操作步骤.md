# 云计算跨层风险穿透评估 Demo 操作步骤

目标地址：`http://172.20.30.201:17003`。本机只准备材料，不需要安装 Node、SQLite 或 Docker；Demo 在测试机 Docker Compose 中运行。材料目录：`测试材料/政务云虚构证据包`。

## 1. 登录并建立项目

1. 打开目标地址。第一次使用时点击“初始化系统”，创建系统管理员；已有系统直接登录。
2. 若首次登录要求改密码，设置一个至少 12 位的新密码。
3. 进入“项目管理”，创建项目，例如：`2026 政务云跨层风险穿透评估演示`。
4. 范围填写：`政务云平台 H01/V1/VM-A1 与政务服务事项、数据库、账号权限、网络隔离和备份控制`。
5. 创建后确认顶部“当前项目”已经切换到刚才的项目。

## 2. 上传证据材料

进入“证据采集与抽取”，逐个选择以下文件并点击“上传并导入”。核心演示上传 8 份；`03_网络拓扑图.pdf` 是可选的扫描/图形材料，用来展示“无法提取文本时保留待处理”。不要上传 `00_上传顺序与核对清单_请勿上传.txt`，它只是本步骤说明。

1. `01_CMDB资源台账.xlsx`：平台主机、资源池、虚拟化组件、网络和安全控制。
2. `02_虚拟化集群与VM承载清单.xlsx`：计算节点、虚拟机、账号和承载业务。
3. `03_网络拓扑与安全策略.pdf`：可提取文本的网络分区、访问控制和失效隔离关系。
4. （可选）`03_网络拓扑图.pdf`：用于验证扫描/图形材料无文本时的待处理状态；若服务器能提取文本，也可以正常抽取。
5. `04_应用数据库业务承载清单.xlsx`：应用、数据库、政务服务事项及数据敏感度。
6. `05_云平台权限与审计日志.json`：账号、权限、调用和审计证据。
7. `06_迁移变更单与操作记录.docx`：迁移、变更窗口和关系时效证据。
8. `07_虚拟化与主机漏洞扫描报告.pdf`：漏洞风险源、主机和虚拟化组件关系。
9. `08_备份加密与安全控制核查记录.docx`：备份、密钥、加密和控制节点。

上传后，左侧列表会显示“已抽取”或“待处理”。普通工作簿不会直接当作图谱模板，而是显示为材料文本，等待模型抽取；只有下载的标准三表模板才会直接按表校验导入。

## 3. 录制真实模型抽取过程

1. 对状态为“待处理”且有内容的材料点击“调用模型抽取”。
2. 右侧“模型解析过程”会显示读取文件、调用 OpenAI-compatible API、等待响应、JSON 字段/枚举/置信度校验、写入图谱和耗时；按钮会禁用并变为“正在解析…”。
3. 抽取完成后点击“查看抽取”，展示候选资产、关系、风险源、来源和置信度。
4. 可录一段模型失败证据：暂时让模型服务不可用，再点击抽取，页面会显示失败日志，材料保持“待处理”，随后恢复服务点击同一按钮即可重试。系统不会用模拟结果补数据。

## 4. 查看跨层资产图谱

1. 进入“跨层资产图谱”。确认平台、租户业务、安全控制三列均有节点，例如 `H01、V1、VM-A1、DB-A、政务服务事项、U01、R01`。
2. 节点卡片查看租户、资源池、业务重要性、数据敏感度、可用性、安全措施、来源和置信度。
3. 关系表查看承载、挂载、部署、调用、网络可达、权限、共享资源、隔离等关系；失效关系显示灰色/虚线。
4. 点击“修订属性”修改节点重要性、敏感度或安全措施，填写理由保存。点击关系表“修订”可切换有效状态并调整 C/N/P/R/E/B/I，保存后会生成复核记录和审计事件。

## 5. 执行穿透计算

1. 进入“风险穿透计算”，点击“重新执行穿透计算”。
2. 页面顶部确认：有效路径数量、被阻断候选路径数量、失效/时效边数量和待补全槽位数量。
3. 风险表查看 P1-P5 优先级、风险等级、穿透等级、路径和租户风险值。
4. 打开一条“明细”，展示 `S`、`Tp`、`Pt`、`Lt`、`Rt`，7 个穿透因子、4 个损失因子、参数快照、处置建议、复核命中和证据链。
5. 打开“计算参数”，可调整权重、α 和四个等级阈值；保存后再次计算，说明参数随项目和风险结果留档。演示默认值为等权重、`α=0.5`、阈值 `0.2/0.4/0.6/0.8`。

## 6. 槽位追问与人工复核

1. 进入“聚焦复核队列”。展示高风险、敏感数据、重要业务、多跳路径或接近阈值的风险，以及系统生成的命中理由。
2. 在右侧槽位区选择一个待回答问题，输入例如“该权限关系当前有效，已在 2026-10-20 完成复核”，点击“写回槽位并重算”。关系有效性追问会自动更新边并重算风险。
3. 如需展示模型追问，点击“模型优化追问”，页面会显示真实模型生成的自然语言问题；模型不可用时保留原问题并显示错误。
4. 在风险项点击“复核”，把风险等级或风险值调整为人工确认值，填写理由后确认回写。前值、后值、人员、时间和理由会进入审计记录。
5. 图谱页修订节点或关系后，再回到风险页重新计算，展示人工回写对结果的影响。

## 7. 查看整改、审计与报告

1. 进入“整改任务”，查看系统根据 P1-P3 风险自动生成的整改项，包括责任人、截止日期、处置建议和状态；可点击“完成”。
2. 进入“审计轨迹”，查看上传、抽取、失败重试、风险计算、追问回答、节点/边修订和风险复核记录。
3. 点击页面右上角“导出报告”，打开 PDF。报告包括项目范围、有效/阻断路径摘要、每条路径与公式计算、穿透等级、证据链、复核命中、处置建议、整改优先级和人工复核记录。

## 8. 录屏建议顺序

登录 → 新建项目 → 上传 8 份材料 → 展示模型解析过程 → 查看抽取来源/置信度 → 查看三层图谱和失效边 → 执行计算 → 打开一条风险明细 → 回答一个槽位 → 人工复核修订 → 查看整改任务 → 查看审计轨迹 → 导出 PDF。
